# Система оформления заказа обуви «Чудо Обувь»

Учебный проект по разработке БД SQLite.

## Автор
- ФИО: Бутарев Кирилл Константинович
- Группа: ИУП 3ИП-13-24
- Курс: 3

## Стек
Python, SQLite, VS Code, GitHub Desktop.

## Запуск
1. Открыть проект в VS Code.
2. Запустить `src/db_init.py` (кнопка ▶).
3. Запустить `src/db_seed.py` (кнопка ▶).
4. Запустить `src/shell.py` (кнопка ▶).

## Структура
- `docs/` — документация
- `src/` — Python-скрипты
- `db/` — SQL и резервные копии
- `queries/` — SQL-запросы
- `data/` — Excel-файлы
